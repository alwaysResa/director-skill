# Changelog

## 0.1.0 — 2026-11-05

Initial release.

- Seven-phase workflow: intake, script, audio, storyboard/HTML, review, render,
  QA/delivery.
- Deterministic Chromium renderer with no npm dependencies.
- Contact-sheet helper for media-safe review.
- 32 MiB inline-media budget guard and recovery guide.
- Video QA script: ffprobe, full decode, loudness, duration, frame count.
- Starter HTML (9:16), five-second demo, generated tone, smoke test, optional
  GitHub Actions template.
